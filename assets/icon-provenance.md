master was generated with the built-in imagegen tool on 2026-10-10, preserving
the reference composition. The generated PNG is 1254 × 1254 pixels, compared
with the 256 × 256 reference. The bundled window PNG is 256 × 256; the Windows
ICO contains 16, 32, 48, 64, 128 and 256 pixel versions of the same image.

solid black square. Preserve silhouette, clockwise central spiral, overlapping
left strokes and separating gaps, rotation, proportions, round caps and margins.
Improve resolution and edge quality only. No redesign, text, gradients, glow,
shadow, mockup or watermark. The tool was asked for 2048 pixels if possible;
